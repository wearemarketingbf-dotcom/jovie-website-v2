# JOVIE Dining Rituals · website v2

A second creative direction for jovie.pk called **Noon to midnight**

JOVIE is open every day from 12 pm to 12 am · the page is one day at the restaurant
the background moves from noon light to midnight as you scroll and a small clock follows along

- `index.html` · the built page (served by GitHub Pages from the repo root)
- `assets/` · images · the hero film loop · the wood-fire frame sequence
- `source/` · `src.html` and `build.py` (run `python3 source/build.py` from the v2 working folder to rebuild)
- Reservations post to the GoHighLevel workflow "JOVIE website reservations" with `source: jovie.pk website v2`
- The page carries `noindex` while it is a preview · remove it before it goes live on jovie.pk
